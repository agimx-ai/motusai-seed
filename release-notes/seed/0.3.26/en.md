# MotusAI Seed 0.3.26

Improve local file operations for plugins and Obsidian plugin updates.

## New

- **File copying**: Copy local files between authorized directories without overwriting existing destination files.

## Improvements

- **Directory browsing**: Support showing directory contents according to system settings, with improved pagination and change synchronization for large directories.
- **Obsidian updates**: Refine how plugin updates are handled after installation.
