# MotusAI Seed 0.3.21

Companion page client icons can be configured through Cloud, with improvements to experience articles and MCP tool calls.

## Improvements

- **Companion page client icons**: Display client names and icons configured through Cloud; keep the previous list or bundled defaults if retrieval fails.
- **Popular experience articles**: Show the number of readers in the past seven days to reflect recent interest.

## Fixes

- **Experience article layout**: Wrap long text within the reading pane and allow wide tables and code blocks to scroll horizontally.
- **MCP tool parameters**: Preserve plugin JSON Schemas when registering tools, avoiding parameter structure changes that affect calls.

## Usage notes

- **Matching versions**: The client and SDK are released together as 0.3.21.
