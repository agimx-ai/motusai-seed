# MotusAI Seed 0.3.21

伙伴页客户端图标支持云端配置，并改善经验文章展示与 MCP 工具调用。

## 改进

- **伙伴页客户端图标**：支持展示云端配置的客户端名称与图标，获取失败时保留已有列表或默认图标。
- **热门经验**：热门文章显示近 7 天阅读人数，帮助了解近期关注度。

## 修复

- **经验文章排版**：长文本在阅读区域内换行，宽表格和代码块可横向滚动。
- **MCP 工具参数**：注册插件工具时保留原有 JSON Schema，避免参数结构转换影响工具调用。

## 使用提醒

- **配套版本**：客户端与 SDK 同步发布为 0.3.21。
