# MotusAI Seed 0.3.27

Upgrade audio recording to save recordings while supporting live transcription.

## New

- **Recording files**: Save WAV files during recording while retrieving live audio frames on demand.
- **Storage alerts**: Show a warning when low disk space prevents local audio from continuing to be saved.

## Fixes

- **Plugin pages**: Fix handling when a plugin is uninstalled while its page is opening.

## Usage notes

- **Coordinated update**: The recording interface has changed. Users of recording and transcription need to update the recording plugin to a compatible version.
