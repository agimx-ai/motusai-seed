# Seed 0.2.8：更新提示与双语工具名称

安装或升级后可查看本版更新说明，插件工具也能向接入应用提供统一的中英文名称。

## 新增

- **更新说明**：安装或升级后展示一次该版本的更新内容，确认后不会重复提示。

## 改进

- **工具名称**：支持插件声明独立的中英文短名称，接入应用可按自己的界面语言显示；调用标识和工具参数保持不变。
- **插件操作**：压缩操作按钮的占用空间，保留原有操作与提示。
- **开发接口**：同步发布 SDK 0.2.2，提供双语名称类型与开发说明。

## 修复

- **长请求处理**：对齐云转发的请求限制，保留请求超限原因，便于 Agent 按正常流程压缩上下文或明确报告失败。

## 使用提醒

- **配套升级**：本次官方插件使用新的名称声明，需要 Seed 0.2.8 或更高版本；请先更新客户端，再更新插件。
