# MotusAI Seed 0.3.22

经验文章支持分享与客户端内打开，插件可使用系统目录选择器。

## 新增

- **经验文章分享**：复制文章分享链接，支持通过链接在 Seed 中打开对应文章。
- **目录选择**：插件可通过 SDK 打开系统目录选择器，选择文件夹作为操作目标。

## 改进

- **点赞反馈**：成功点赞时显示动画，并遵循减少动态效果设置。

## 修复

- **经验页操作**：修复顶部操作区在部分页面状态下的展示问题。

## 使用提醒

- **配套版本**：客户端与 SDK 同步发布为 0.3.22。使用目录选择接口的插件需要此版本或更新客户端。
