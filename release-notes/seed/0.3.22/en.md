# MotusAI Seed 0.3.22

Share experience articles and open them in Seed, with a system folder picker for plugins.

## New

- **Experience article sharing**: Copy an article's sharing link and open the corresponding article in Seed through its link.
- **Folder selection**: Plugins can use the SDK to open the system folder picker and select a directory.

## Improvements

- **Like feedback**: A successful like displays an animation that respects the reduced motion setting.

## Fixes

- **Experience page actions**: Fixed the display of header actions in some page states.

## Usage notes

- **Matching versions**: The client and SDK are released together as 0.3.22. Plugins using the folder picker require this client version or later.
