# MotusAI Seed 0.2.15

新增通用的模型与思考等级选择体验，完善插件设置自动保存、主题图标和连接状态，并提高插件更新与客户端下载可靠性。

## 新增

- **模型与思考等级**：插件可在设置表单中使用统一选择组件，模型列表、分组和逐模型思考等级均由插件提供，Seed 负责一致呈现。
- **设置自动保存**：插件可声明修改后自动保存的独立设置表单，不再需要额外点击保存按钮。

## 改进

- **选择体验**：标题和思考等级固定显示，模型列表独立滚动；支持鼠标、键盘和焦点交互，并针对表单场景统一高度、圆角、边框和间距。
- **主题图标**：供应商可分别提供浅色与深色图标；彩色图标保留原色，单色图标随主题正确显示。
- **连接状态**：插件配置档案的连接状态改为更清晰的胶囊标签，支持在可重连状态直接操作。

## 修复

- **插件重载**：插件定义变化后使用最新运行定义重新启动，避免安装或更新后继续运行旧快照。
- **更新下载**：客户端更新改用单范围请求，提高对象存储和代理环境下的下载兼容性。

## 使用提醒

- **配套插件**：建议同时更新 Agent Harness 0.2.30、企业微信机器人 0.2.6，以及首次发布的微信机器人 0.1.0。
- **Seed SDK 0.2.6**：公开模型分组、思考等级和深浅主题图标配置类型。
