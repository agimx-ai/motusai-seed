# MotusAI Seed 0.3.16

插件入口、页面导航和内容展示更加完整，伙伴页介绍支持云端配置。

## 新增

- **插件导航入口**：插件可通过 SDK 注册侧栏分组、页面和右上方「+」菜单操作，支持角标与亮暗 SVG 图标，保留 Lucide 图标用法。
- **前进与后退**：可在客户端浏览记录中前进、后退，窗口导航同时适配 macOS 和 Windows。
- **减少动态效果**：设置中可选择跟随系统、开启或关闭，客户端与 SDK 组件按同一偏好调整动画。
- **伙伴页介绍**：支持从 Cloud 获取中英文介绍与启用状态；链接选填，有链接时显示跳转箭头，无链接时仅展示介绍气泡。

## 改进

- **侧栏布局**：支持拖动调整宽度，优化层级缩进、图标对齐、键盘焦点与快捷菜单间距；长标题改为尾部渐隐。
- **插件独立页面**：优化顶部标题、操作按钮与面包屑间距，支持由插件控制横向内容布局，并可打开自己的设置页。
- **Markdown 展示**：统一表格样式与吸顶表头，工具栏保留复制操作；提供通用表格背景变量，以及由调用方控制的图片和链接渲染接口。
- **文本与文件操作**：SDK 支持可选择文本及原生编辑菜单，插件可在获准范围内打开文件或选择打开方式。
- **伙伴页布局**：调整介绍气泡、复制栏和客户端图标之间的空间，底部内容按实际高度参与布局。

## 修复

- **插件页面恢复**：修复热加载后当前页面一直显示加载中的问题；单个页面打开失败不再影响其他页面和侧栏入口。
- **弹窗提示**：修复弹窗关闭、焦点返回按钮时误触发悬停提示的问题。
- **Cloud 资源访问**：读取和订阅均按插件实际获准访问的资源校验，限制跨资源访问。
- **诊断记录**：按记录时间收集指定范围内的活动 JSONL 会话，保留相关会话的完整内容。

## 使用提醒

- **配套版本**：客户端与 SDK 同步更新为 0.3.16。插件最低客户端版本应按实际使用的接口填写。
- **介绍配置**：无链接介绍需要 Cloud 和客户端同时支持；旧客户端无法接受此类配置时会继续使用上次有效缓存。
