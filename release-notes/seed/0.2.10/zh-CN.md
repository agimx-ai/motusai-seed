# MotusAI Seed 0.2.10

修复会话积分漏算工具费用的问题，并稳定 macOS 客户端图标生成与显示。

## 修复

- **积分统计**：为插件提供实际结算回执，使会话消耗可以包含模型、搜索、网页读取等工具费用；嵌套调用按调用 ID 去重，不以报价或工具返回内容推算费用。
- **结算完整性**：结算未知、失败或尚未完成时，不显示误导性的部分合计；实际扣费规则保持不变。
- **客户端图标**：修复构建时偶发生成空白图标的问题，增加生成校验；打包版保留原生 macOS 26+ 液态玻璃图标，不再被开发环境 Dock 图标覆盖。

## 使用提醒

- **配套更新**：积分统计修复需搭配 Agent Harness 0.2.23；旧会话缺少工具结算回执时无法补算历史总额。
- **插件开发**：SDK 0.2.3 新增可选结算回执接口，默认能力调用仍返回原有业务结果。
