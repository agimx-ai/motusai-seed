# MotusAI Seed 0.3.15

更方便地查找插件、查看活动与设置外观，改善录音恢复，并支持更丰富的功能介绍。

## 新增

- **插件筛选**：在搜索中按标签和具体组织筛选插件，更快找到需要的工具。
- **功能介绍**：支持视频和 Markdown 介绍，视频可配置封面，文字内容随亮暗主题展示。
- **插件用户资料**：SDK 提供只读昵称与头像接口，供网页发布等插件使用当前账号的公开资料，不额外传递登录凭据。

## 改进

- **活动记录**：整合搜索与分类筛选，显示每日活动总数，优化卡片、状态和间距，保留插件启动失败的具体原因。
- **外观设置**：按外观、系统与关于重新分组，使用可视化主题预览，统一开发与正式客户端的 macOS 原生图标表现。
- **共享弹窗**：调整 SDK 弹窗底部间距，使操作区更加紧凑。

## 修复

- **录音恢复**：电脑休眠时暂停采集，唤醒后等待实际音频恢复再继续，累计时长排除休眠时间；需配合更新录音转写插件。
- **连接恢复**：修复唤醒后取消尚未完成的 WebSocket 连接时可能出现的异常。
- **活动分页**：切换筛选时忽略过期响应，避免分页结果重复或混入其他条件的数据。
- **账号头像**：头像加载失败后可自动重试，改善临时网络异常后的展示。

## 使用提醒

- **配套版本**：客户端与 SDK 同步发布为 0.3.15。使用新用户资料接口的网页发布插件需要此版本或更新客户端。
