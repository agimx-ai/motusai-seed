# MotusAI Seed 0.3.0

更新插件框架，新增云端功能介绍，并统一插件设置和选择体验。

## 新增

- **新插件框架**：插件独立提供功能和设置界面，Seed 提供通用组件、权限和运行能力。
- **功能介绍**：接收云端配置的图文介绍，支持沉浸背景、上图下文及多条切换；已读状态保存在本机。
- **多级选择**：共享下拉组件支持分级选项，菜单宽度稳定并支持键盘操作。

## 改进

- **插件页面**：统一列表字体和图标、流程连线和按钮布局；已安装图标均匀排列，保留原有尺寸。
- **界面解耦**：模型分组、业务选项和文案由插件提供，隐藏无需向用户展示的工具名称。
- **文件协作**：提供受控文件变更监听，供个人助理等插件响应授权目录中的变化。

## 使用提醒

- **配套插件**：本版本使用 Plugin API v2，请同时更新对应的官方插件；旧版插件需要迁移后才能在本版本运行。
- **开发工具**：插件开发使用 Seed SDK 0.3.0 与 seed-plugin-tools 0.1.0。
