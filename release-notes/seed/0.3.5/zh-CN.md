# MotusAI Seed 0.3.5

新增 Ubuntu 桌面安装包，与 Windows、macOS 使用同一套正式构建与发布流程。

## 新增

- **Ubuntu 安装包**：提供 Ubuntu 24.04 x86_64 的 DEB 安装包及 Linux 更新清单。

## 修复

- **Linux 应用图标**：补齐系统图标主题使用的常规尺寸，统一启动器和窗口标识，避免显示默认齿轮图标。

## 使用提醒

- **桌面环境与安全存储**：请在正常桌面会话中启动应用；登录凭据依赖系统密钥环，安全存储不可用时不会降级为明文保存。Ubuntu 登录与原生能力仍需实机验收。
- **Linux 录音范围**：当前支持麦克风采集，暂不支持系统音频和混音。电脑操作等原生能力受桌面会话和系统权限限制。
