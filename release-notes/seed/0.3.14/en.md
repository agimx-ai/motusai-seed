# MotusAI Seed 0.3.14

Let plugins open the system browser automatically for a smoother authorization flow.

## New

- **Plugin browser authorization**: Authorized plugins can open sign-in pages in the default system browser, including LAN HTTP sites and HTTPS sites, without requiring users to copy authorization links manually.

## Usage notes

- **Matching versions**: The client and SDK are released together as 0.3.14. Sinno Agent OS requires this version or a later client for automatic authorization.
