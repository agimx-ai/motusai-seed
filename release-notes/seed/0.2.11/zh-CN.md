# MotusAI Seed 0.2.11

增强插件文件写入保护，为原生画布等逐步生成文件的工具提供安全保存能力。

## 新增

- **仅新建文件**：文件 Broker 支持仅创建新文件，同名文件已存在或被其他调用抢先创建时拒绝覆盖。

## 改进

- **版本检查**：串行处理同路径写入，并在替换前再次核对文件版本；持有旧版本的调用不能重新创建已删除的文件。
- **完整保存**：先生成完整临时文件再发布，成功及失败后均清理临时文件。

## 使用提醒

- **编辑边界**：磁盘版本检查不保护外部应用尚未保存的编辑，也不是跨进程原子比较交换；请避免人工与 Agent 同时编辑同一文件。
