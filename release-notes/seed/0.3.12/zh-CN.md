# MotusAI Seed 0.3.12

加入插件开发模式和伙伴首页接入入口，改进开发加载反馈、文件浏览与界面细节。

## 新增

- **插件开发模式**：在插件设置中开启后，自动加载并热更新本机开发插件；源码启动和正式安装版共用同一个开关，关闭后恢复已授权的正式插件并保留数据。
- **AI 客户端接入**：伙伴首页提供安装指令复制入口，便于将 Seed 工具接入 Claude Code、Codex、DeepSeek Harness、WorkBuddy 和 VS Code。

## 改进

- **开发加载反馈**：SDK 开发工具分别提示产物同步、等待客户端、开关关闭、正在加载、加载成功和失败原因，只确认当前构建的加载状态。
- **官方示例工程**：开发文档加入 [seed-sample-plugin](https://github.com/agimx-ai/seed-sample-plugin) 模板入口，提供可直接构建、测试和修改的插件工程。
- **界面与菜单**：优化伙伴首页图标、悬停反馈和消息提示间距，简化原生菜单，并提供开发者工具快捷键。

## 修复

- **文件浏览**：目录中存在无权限或已移除的条目时，跳过不可读取的条目，继续显示其他文件。
- **图标与错误提示**：图标加载失败时显示替代内容，统一错误提示文案与显示细节。

## 使用提醒

- **配套版本**：客户端与 SDK 同步发布为 0.3.12。插件开发模式默认关闭；使用新版 CLI 加载反馈时，请同时升级客户端和 SDK。
