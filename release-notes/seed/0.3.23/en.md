# MotusAI Seed 0.3.23

Plugins can subscribe to live audio, with improvements to image previews, notifications, and experience articles.

## New

- **Live audio subscriptions**: Plugins can use the SDK to receive live audio chunks from the microphone, system audio, or both, and pause or stop capture.

## Improvements

- **Image previews**: View images full-screen and navigate through multiple images in order.
- **Notifications**: The sidebar bell combines plugin update and experience article notification counts.
- **Experience articles**: Detail pages show the author's avatar, relative publication time, share count, and recent reader avatars.
- **Sidebar name**: The application name follows the interface language.

## Usage notes

- **Matching versions**: The client and SDK are released together as 0.3.23. Plugins using live audio subscriptions require this client version or later; the existing segmented recording interface remains supported.
