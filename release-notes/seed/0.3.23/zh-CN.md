# MotusAI Seed 0.3.23

插件支持实时音频订阅，图片预览、通知和经验文章展示得到改进。

## 新增

- **实时音频订阅**：插件可通过 SDK 接收麦克风、系统音频或混合音源的实时音频块，并控制暂停和停止。

## 改进

- **图片预览**：全屏查看图片，支持按顺序切换多张图片。
- **通知入口**：侧栏铃铛汇总插件更新与经验文章提醒数量。
- **经验文章**：详情页展示作者头像、相对发布时间、分享次数及最近阅读者头像。
- **侧栏名称**：应用名称随界面语言显示。

## 使用提醒

- **配套版本**：客户端与 SDK 同步发布为 0.3.23。使用实时音频订阅的插件需要此版本或更新的客户端；已有分段录音接口继续支持。
