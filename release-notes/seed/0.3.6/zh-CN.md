# MotusAI Seed 0.3.6

为插件提供统一的系统通知接口，并简化客户端升级后的插件更新。

## 新增

- **系统通知**：插件可通过 Seed SDK 发送带标题、正文和图片的通知，处理显示、点击和关闭事件，并自行决定是否跳转。
- **通知开关**：在常规设置中控制客户端的系统通知，默认启用。

## 改进

- **升级后更新插件**：客户端升级后自动检查并更新已安装插件，可在插件设置中关闭。

## 修复

- **开关位置**：修正开关滑块偏下的问题，使滑块在轨道内居中。

## 使用提醒

- **系统通知范围**：SDK 只提供 macOS、Windows、Linux 共同支持的接口；是否显示、能否点击以及关闭事件由系统权限、勿扰设置和桌面通知服务决定。
- **插件兼容性**：本次配套升级的官方插件最低需要 MotusAI Seed 0.3.6。
