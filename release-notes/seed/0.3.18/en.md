# MotusAI Seed 0.3.18

Explore and manage shared experiences with the new tips section.

## New

- **Tips**: Browse, search and like tips, switch between latest and popular, and check submission status and feedback under My submissions.
- **SDK reader and companion**: Reuse article rendering, themes and the companion component in your applications.

## Improvements

- **Article reading**: Article themes adapt to the client's light and dark modes, and the list refreshes when tips change.
- **Companion prompts**: Adjusted when discovery bubbles appear.

## Usage notes

- **Matching versions**: The client and SDK both update to 0.3.18. Plugins using the new SDK APIs should require this client version or later.
