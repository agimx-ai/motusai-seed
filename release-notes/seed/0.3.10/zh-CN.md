# MotusAI Seed 0.3.10

为插件提供多级面包屑与返回，让子页面更聚焦，并改善通知的按钮与长内容布局。

## 新增

- **插件多级导航**：插件可通过 SDK 设置头部面包屑，点击上级层级或返回上一级。长路径优先保留首级和最后两级；悬停或键盘聚焦中间层级时展开文字，后面的层级按需压缩。

## 改进

- **子页面展示**：进入插件子页面时收起插件信息与更新说明，返回插件首页后恢复，切换层级无需重新加载插件页面。
- **头部交互**：“插件”保留原有标题样式，面包屑悬停背景更紧凑，文字与箭头位置保持不变。

## 修复

- **通知布局**：操作按钮配色跟随通知类型，多行内容与按钮自动分行排列，修正深色主题下的取消按钮样式，并改善键盘焦点显示。

## 使用提醒

- **SDK 版本**：客户端与 `@motus-ai/seed-sdk` 从本版起使用相同版本号。多级导航需要客户端与 SDK `0.3.10` 或更新版本；兼容旧客户端的插件应先检查 `app.navigation` 是否可用。
