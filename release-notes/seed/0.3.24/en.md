# MotusAI Seed 0.3.24

Install and update MotusAI for Obsidian more easily from Seed, with improvements to notifications and localization.

## New

- **Obsidian integration**: View the installation status and version of MotusAI for Obsidian under app integrations on the plugins page, and install or update it for registered vaults.

## Improvements

- **Update notifications**: The sidebar notification includes Obsidian plugin updates, with motion feedback on the bell and badge.
- **Application name**: Improved localized names in the macOS menu and Dock, and in settings.
- **Interface details**: Refined the layout and icons on the plugins page and sidebar navigation.

## Usage notes

- **Enabling the plugin**: After installation or an update, follow the on-screen instructions to enable the plugin or reload it in Obsidian.
