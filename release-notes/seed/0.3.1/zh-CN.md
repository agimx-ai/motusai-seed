# MotusAI Seed 0.3.1

修复插件更新、活动记录与图片显示问题，提升正式插件和开发插件并存时的稳定性。

## 改进

- **活动记录**：同一次请求中的插件调用合并到一张卡片，隐藏内部轮询与传输记录，并使用面向用户的标题代替请求地址。
- **插件来源选择**：开发版和正式版并存时优先运行版本号更高的插件，同版本继续保留开发热更新能力。
- **插件图片**：允许插件页面显示 HTTP 与 HTTPS 图片，避免合法远程图片被错误拦截。

## 修复

- **活动列表恢复**：修复真实活动位于内部技术链路下时列表显示为空的问题。
- **连接文案**：优化本地客户端授权记录中的名称间距。
