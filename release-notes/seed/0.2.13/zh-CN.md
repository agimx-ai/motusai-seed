# MotusAI Seed 0.2.13

支持插件成功后结算固定服务费和运行历时展示，并修复失败调用的积分回执传递。

## 新增

- **本地插件计费**：插件可沿用 Cloud 计费产品配置，在成功完成后结算固定服务费；失败和取消不收取这笔费用，重复请求与重启恢复沿用原调用记录。
- **运行历时**：声明式状态面板支持在状态旁显示本地化历时，供插件更新运行中耗时并保留结束后的结果。

## 修复

- **失败调用积分**：跨插件与原生进程调用失败时保留已确认的结算回执，避免已扣积分因工具报错而从会话总额中丢失；未确认费用仍保持未知。

## 使用提醒

- **配套插件**：更新 Agent Harness 0.2.29 和 IQ 草案生成 0.1.22，以使用对应的异常状态、收费与历时功能。
