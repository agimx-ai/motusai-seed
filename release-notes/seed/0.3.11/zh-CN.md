# MotusAI Seed 0.3.11

插件独立更新，不再连带重启其他插件，并加入侧边栏剩余额度圆环。

## 新增

- **积分圆环**：侧边栏显示本轮剩余额度，按最近一次积分到账后的余额重新起算；外圈根据剩余比例显示绿、黄、红色，中间菱形保持灰色。提示只显示剩余百分比和额度，点击打开使用情况。

## 修复

- **独立重载**：更新或配置一个插件时保留未变更插件的运行实例，让工具消费者动态刷新可用能力。
- **后台工具调用**：已结束请求的调用链不再污染后台任务，运行进度查询不再造成循环误判；保留真实循环拦截、审批和审计。
- **系统代理**：提供受权限约束的系统代理解析，让插件请求使用系统配置的网络路由。

## 使用提醒

- **配套版本**：客户端与 SDK 同步发布为 0.3.11；本次 Agent Harness 和企业微信机器人更新需要先升级客户端。
