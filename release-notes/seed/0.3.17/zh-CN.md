# MotusAI Seed 0.3.17

SDK 提供公开的动画偏好接口，方便插件自定义动效跟随客户端的「减少动态效果」设置。

## 新增

- **动画偏好读取**：可从 SDK 导入 `prefersReducedMotion()`，在触发动画前读取当前偏好；客户端选择优先，跟随系统时使用系统偏好。
- **React 动画偏好**：可从 React 入口导入 `useReducedMotion()`，随客户端选择或系统偏好变化自动更新，组件卸载时释放监听。

## 使用提醒

- **配套版本**：客户端与 SDK 同步更新为 0.3.17。使用这两个接口的插件应要求此版本或更新客户端。
- **自定义动效**：插件需要主动接入接口，并自行停止或恢复动画；仅升级客户端或 SDK 不会自动改变插件已有的动效逻辑。
