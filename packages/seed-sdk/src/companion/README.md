# Bloub animation core

This directory contains the geometry, pose data, SVG animation engine, and React component for the Seed companion. It was extracted from [jeremy-prt/bloub](https://github.com/jeremy-prt/bloub) at commit `b4bb3c1b5f93c7b87a2e8d620f667c4093d97749`.

The upstream Vue application, animation editor, customizer pages, export tools, routing, styles, and UI components are intentionally not included. Seed maps framework task snapshots to engine states in its application layer.
