# MotusAI Seed 应用更新

Seed 使用 `electron-updater`，更新源采用 `electron-builder` 的通用更新源格式。开发版本不会访问更新源；打包版本会在启动后检查一次，之后每四小时检查一次。

Seed 启动时会根据当前系统和架构向 Seed Cloud 获取签名的客户端配置文档。OAuth、插件目录、更新源和事件 WebSocket 以该文档为准；官网地址 `https://motusseed.com` 内置于客户端，运行服务连接由插件管理。Seed Cloud 发布新版本或切换当前版本后会发送失效通知，客户端重新读取权威配置文档并立即检查更新。打包版本仍会在启动后检查一次，之后每四小时检查一次作为断线兜底；运行服务不参与客户端版本发现或更新推送。

没有可用更新时，侧边栏继续显示帮助图标。发现新版本后，Windows 显示蓝色更新操作，下载过程中显示紧凑的蓝色下载状态，下载完成后提供“重启并更新”操作。macOS 在尚未启用 Developer ID Application 签名与 Apple 公证期间显示“下载新版本”，点击后通过系统浏览器下载更新源中声明的 DMG，由用户退出应用后手动替换安装。

## 客户端配置

更新地址由 Seed Cloud 根据发布通道、当前系统和架构自动生成，再通过签名的客户端配置文档下发。客户端不重复维护更新地址。

应用名称、应用 ID 和图标资源固定为统一的 MotusAI Seed 客户端。构建时提供 Seed Cloud 地址、发现文档公钥、更新通道和目标平台：

```dotenv
MOTUSAI_SEED_CLOUD_URL=https://cloud.motusseed.com
MOTUSAI_DISTRIBUTION_KEY_ID=motusai-cloud-production-v1
MOTUSAI_DISTRIBUTION_PUBLIC_KEY=MCowBQYDK2VwAyEAGhcDBccJ1TtieZrAO1YFMs7sL7s7JuvtKPJFB7BheTc=
MOTUSAI_UPDATE_CHANNEL=stable
MOTUSAI_RELEASE_PLATFORM=mac-arm64
```

`MOTUSAI_DISTRIBUTION_PUBLIC_KEY` 是单行 Base64 SPKI DER 公钥，不是秘密。`electron-builder.config.mjs` 会从这些值推导 Seed Cloud 通用更新源 URL。Seed Cloud 签名私钥不得进入客户端仓库或构建产物。

然后打包对应平台：

```bash
npm run package:mac
```

其他构建应使用与目标平台匹配的目录，例如 `win-x64`、`mac-x64` 或 `mac-universal`。生产环境更新源应使用 HTTPS。

打包前的 `npm run icons:generate` 等待 SVG 解码后通过 Canvas 直接生成静态图标，不依赖窗口截图时序。生成阶段会校验尺寸及 Logo 主体、眼睛像素；空白或只有底色的图标必须使构建失败，不能仅检查文件存在。原始 SVG 与应用内吉祥物动画保持不变。

可运行 `npm run icons:verify` 复核已生成的 PNG 和 Icon Composer 图层；核对安装包时运行 `npm run icons:verify -- "/path/to/MotusAI Seed.app/Contents/Resources/app"`。macOS 正式版使用包内原生图标，不在启动时用 PNG 覆盖 Dock 图标；开发版仍单独设置 Dock 图标。

构建产物写入 `release/`。macOS 稳定版会生成 `latest-mac.yml`、ZIP、DMG、各自的 blockmap，以及可直接上传 Seed Cloud 的 `mac-*-update-feed.zip`；Windows 稳定版会生成 `latest.yml`、NSIS EXE、对应的 blockmap 和 update-feed ZIP。

macOS update-feed ZIP 包含 `latest-mac.yml`、应用更新 ZIP、DMG 和二者各自的 blockmap；Windows update-feed ZIP 包含 `latest.yml`、NSIS EXE 和对应的 blockmap。平台管理员在 Seed Cloud 的客户端版本页面选择对应通道和平台并上传该 ZIP；验证通过后它会成为当前版本。官网和 macOS 客户端通过 Seed Cloud 的固定 `/download` 地址获取当前 DMG，Windows 对应地址获取当前 EXE。

Seed Cloud 会校验 ZIP 内的文件集合、元数据、平台安装包扩展名、文件大小和 SHA-512，再将对应平台的更新与安装资产作为不可变对象保存。重新上传同一版本不能覆盖不同内容；需要回退时，在版本历史中将已有版本设为当前版本。

## 生产环境发布要求

macOS 发布版本必须使用 Developer ID Application 证书签名并完成 Apple 公证；Windows 发布版本应使用 Authenticode 签名。生产环境的 `API_PUBLIC_URL` 应使用 HTTPS，并指向客户端可访问的 Seed Cloud API 或其前置 CDN。
