# Bloub 吉祥物验收清单

## 预览

从仓库根目录运行：

```bash
.agents/skills/mascot-maintainer/scripts/start-preview.sh
```

预览在 `http://127.0.0.1:4178/` 直接渲染生产组件，可切换状态组、浅色/深色、正常/减弱动态和放大模式。只生成临时文件时使用 `--prepare-only`。

至少覆盖：

- 全部任务、录音和空闲连接状态；
- 活动任务或录音与各连接附属状态的组合；
- 零任务、单任务和多任务对应的展示逻辑；
- 浅色与深色；
- 正常动画与减弱动态；
- 空闲、工作、失败和连接状态的点击反馈；
- 动画开始、中间、稳定及返回帧；
- 页面实际响应式尺寸和放大视图。

## 动画与 SVG

- 状态变化在同一个 `BotEngine` 上连续形变，没有瞬切或重新挂载。
- 正常模式下 body path 和相关装饰持续更新；后台恢复不会大幅跳帧。
- 点击反应结束后自然回到当前框架状态。
- 减弱动态模式没有 rAF 循环，但每个状态仍有清楚的静态轮廓。
- 眼睛和通知缺口是 mask 孔洞，移动到轮廓边缘时裁切正确。
- 后轨道被身体遮挡，前轨道保持可见；粒子前后关系正确。
- 没有 NaN、空 path、重复 mask ID、控制台错误或警告。

## 状态与框架

- `running → working → review/failed → idle` 遵守共享时序。
- 并发任务不会提前回到空闲，数量文案正确。
- 录音状态优先级正确，停止录音时不会把录音调用本身算作额外任务。
- 活动任务期间连接异常只显示 `connectionAccessory`。
- Socket、插件间及本地来源的能力调用都经过 `GlobalTaskActivityObserver`；同一调用不会重复上报。
- 渲染代码不包含插件 ID、能力名称或插件专用触发分支。

## 品牌与布局

- default 与 sinno 构建分别读取自己的 `brand.json`，浅色和深色主体填充与当前品牌配置一致。
- 页面底色、眼睛孔洞和粒子深度混合在两种主题下都清楚。
- 通知蓝点以及连接红黄绿提示没有被品牌色覆盖。
- 默认窗口下吉祥物是页面主视觉；小窗口不裁切，宽窗口不超过 208px。
- 连接附属点随整体尺寸保持合适比例和位置。
- 按钮焦点轮廓完整，状态文字与吉祥物间距自然。

## 自动化检查

```bash
npm test
npm run typecheck:raw
npm run build:renderer
git diff --check
```

这些命令只证明行为、类型、构建和格式正确，不能替代观看动画。Vite 包体积警告应单独报告，不能把它描述成视觉验收。
